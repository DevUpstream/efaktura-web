# 08 – Плаќања, наплата и изводи од банка (05.11.2026)

Модул `payments` („Плаќања и наплата“), се вклучува по фирма. Слика `20261105-d5e43d7` (ја содржи и `6e77941`). 114 автоматски теста.

## Плаќања и наплата

| Дел | Каде |
| --- | --- |
| **Наплата:** отворени излезни фактури по купувач, по доспевање (не е доспеано, 1–30, 31–60, 61–90, над 90 дена), детали по фактура | Плаќања и наплата → Наплата |
| **Обврски:** отворени прокнижени влезни фактури по добавувач | → Обврски |
| **Уплата / плаќање:** распоред автоматски од најстариот документ или рачно; преплата останува нераспоредена | „Нова уплата“, „Уплата“ кај купувачот |
| **Сторно на уплата** – фактурите повторно се отвораат | → Уплати |
| Салдо на купувачот | Картичка на купувач |

Правила: отворено = „За плаќање“ − книжни одобренија − распоредени уплати; сторнирани и заменети фактури не се долг; уплата не се менува и не се брише (тригер); истовремени внесови за иста фирма се редоследуваат.

## Изводи од банка

### Формат (проверен на вистински изводи, 05.11.2026)

**Халкбанк и Шпаркасе** даваат ист TXT формат со фиксна ширина (UTF-8, CRLF):

| Ред / колона (знаци) | Содржина |
| --- | --- |
| ред 1 | број на извод |
| ред 2 | датум (dd.MM.yyyy) |
| ред 3 | наша сметка (XXX-XXXXXXXXXX-XX) |
| ред 4 / 5 | претходна / нова состојба (`1,234.56`) |
| 0–70 | назив на налогодавач / примач |
| 70–88 | негова жиро-сметка |
| 88–107 | износ со знак (− = одлив) |
| 107–113 | шифра на плаќање |
| 113–185 | цел на дознака |
| 185–209 | повикување на број (задолжување) |
| 209–233 | повикување на број (одобрување) |
| 233–257 | ЕДБ (само Шпаркасе). **Кај ПП50 кон Трезор тоа е нашиот ЕДБ** – никогаш не се препознава како партнер |
| 257–281 | непознато поле (се чува) |

**Стопанска, Комерцијална, НЛБ:** форматот не е проверен. Ако не е ист, увозот одбива со јасна порака (не погодува); тогаш треба примерок за да се додаде. CSV од која било банка работи со мапирање на колоните (се памти по фирма).

### Проверки при увоз
1. **Претходна состојба + промет = нова состојба**, инаку изводот не е целосен или не е точно прочитан → одбиено.
2. **Сметката од изводот мора да е на фирмата** (IBAN / жиро-сметки од „Поставки и PDF“); иста сметка не може да има изводи кај две фирми.
3. **Ист извод не се увезува двапати** (ист документ или иста сметка + број + датум); ист ред не се книжи двапати.

### Препознавање (автоматско поврзување со фактури)

**Партнер**, по сигурност:

| # | Правило | Сигурност |
| --- | --- | --- |
| 1 | ЕДБ во колоната на изводот | сигурно |
| 2 | Жиро-сметка (рачно внесена или **научена** при претходно книжење) | сигурно |
| 3 | Цел број на наша фактура во целта/повикувањето (`MC-2026-4` = `MC-2026-00004`) | сигурно |
| 4 | ЕДБ (13 цифри) во текстот на целта | предлог |
| 5 | Назив (без ДООЕЛ/ДОО/АД, латиница = кирилица), само ако е единствен | предлог |

**Фактури**, кога партнерот е познат:

| # | Правило | Сигурност |
| --- | --- | --- |
| a | Цел број на фактура | сигурно |
| b | Број/година (`4/2026`, `2026-4`) кај фактурите на тој партнер | сигурно |
| c | Точен износ на една отворена фактура | сигурно |
| d | **Единствена комбинација** на отворени фактури со точен збир (до 16 фактури) | сигурно |
| e | Број на фактурата на добавувачот во целта (за плаќања, на пр. ЕСМ `25-1200-230`) | сигурно |
| f | Инаку од најстарата | предлог |

**Сигурно = партнер по 1–3 И фактури по a–e.** Само сигурните се книжат автоматски (може да се исклучи). Предлозите и непознатите чекаат: „Прокнижи“ (со избор на партнер, автоматски или рачно по фактура) или „Не се книжи“ (провизии, плати, Трезор). Рачното книжење ја **учи жиро-сметката** – следниот извод од истиот купувач е сигурен.

Совети за повеќе автоматика:
- Внесете ги ЕДБ-ата на купувачите (од регистарот на УЈП).
- На PDF-от на секоја издадена фактура што се плаќа стои **„При плаќање, во „повикување на број“ наведете: MC-2026-00004“** (слика `20261105-f56d69c`; се исклучува во „Поставки и PDF“). Не се печати на нацрт, сторно, книжно одобрение и платена фактура.

## Отворено / за 10

- Примерок TXT од **Стопанска, Комерцијална, НЛБ** (со избришани имиња) за проверка на форматот.
- Опомени за задоцнети фактури; компензации; камата за задоцнување (стапката да се провери).
- Автоматско означување на провизиите (шифра 666/674 кај Шпаркасе/Халк) како „не се книжи“ – по потврда дека шифрите значат исто кај сите банки.

# 06 – Решение надвор од Microsoft 365: сервер на Oracle (состојба 05.11.2026, 00:30)

Веб-апликацијата (React + Node/Fastify + PostgreSQL) на Oracle е **целосна замена** за Power Apps/SharePoint решението, плус модули што Power Apps ги нема (купувачи-CRM, плаќања и наплата, влезни фактури, магацин, производство). **Праќањето до УЈП од новата апликација уште не е поврзано** (види „Следно“).

Копија на овој документ е и во git: `DevUpstream/efaktura-web/docs/`.

## Сервер
- SSH: `ssh -i "$env:USERPROFILE\.ssh\oracle-efaktura.key" ubuntu@92.5.149.62` (клучот копиран од OneDrive во `.ssh`, ACL само за корисникот). **Командите за серверот секогаш се пуштаат преку оваа ssh линија од PowerShell, не директно во PowerShell** (лекција O21).
- Firewall: iptables (22, 80, 443) + OCI Default Security List (Ingress TCP 80,443).
- `/opt/efaktura`: `docker-compose.yml`, `Caddyfile`, `.env` (од `app.env` + API_TAG), `bin/` (backup скрипти), `backups/` (700), `secrets/` (700 root, датотеки 444): `db_password`, `app_key` (генерирани на серверот), `entra_client_secret`, `backup_par_url` (внесени со `set-secret.sh`). Празна `entra_client_secret` = Entra исклучен.
- Сервиси: caddy, db (postgres:17-alpine), api (ghcr.io/devupstream/efaktura-api, со веб-апликацијата). systemd: `efaktura-backup.timer`.
- `docker login ghcr.io` со PAT `read:packages` (90 дена, **истекува ~02.02.2027**) – на серверот, како root.
- Скриптите за распоредување на серверот се во `~/efaktura-deploy` (не `/tmp`).

| # | Лекција |

| O1 | Oracle Ubuntu сликите имаат iptables REJECT правило – портите се додаваат ПРЕД него и се зачувуваат пред инсталација на Docker. |
| O2 | Покрај iptables треба и Ingress правило во Security List на subnet-от. |
| O3 | Caddyfile монтиран како една датотека: по замена контејнерот ја гледа старата → restart на caddy. |
| O4 | Docker secret монтиран од датотека ги задржува дозволите од host-от → 444 во папка 700 root. |
| O5 | plpgsql нема гарантирана скратена евалуација на AND – `OLD.kind` во тригер за повеќе табели мора во вгнездено IF. |
| O6 | `scp -r` од Windows прави папка без право на пишување → `sudo rm -rf` пред ново копирање. |
| O7 | PowerShell не го третира `\"` како bash – тајни се внесуваат со скрипта на серверот (`set-secret.sh`). |
| O8 | `.env` не може да се запише во папката преку алатките на Claude → `app.env`. |
| O9 | Копирање во OneDrive папката може да пријави успех без замена – секогаш проверка со sha256; запишување со пренасочување `>`. |
| O10 | `wc secrets/*` како ubuntu не работи (glob пред sudo во папка 700) → `sudo sh -c '...'`. |
| O11 | **SharePoint ги чуваше износите по ставка на 2 децимали**, иако правилото е 4. Новата база чува 4 децимали. |
| O12 | Датумите „Date only“ од SharePoint се извезуваат како локално време со offset; се зема само датумот. |
| O13 | `docker compose cp` прави датотека на root → бришење со `exec -u root`. |
| O14 | `@fastify/static` со `wildcard: false` ги регистрира датотеките при старт – по нова сборка рестарт. |

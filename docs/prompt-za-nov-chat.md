# Промпт за нов разговор – е-Фактура (состојба 14.11.2026)

Залепи го текстот подолу како прва порака во нов разговор во проектот FakturiUJP.

Продолжуваме проектот е-Фактура. Одговарај на македонски (80 % по ASD-STE100: кратки реченици, една наредба во реченица), кодот на англиски. Биди критичен и давај оценка + што треба за 10. **Не ги читај сите документи.** Читај само она што е потребно за задачата. Претпоставки: [ПРЕТПОСТАВКА]; непроверени команди: [НЕТЕСТИРАНО].

**Состојба**
- Веб-апликацијата ја замени Power Apps. Repo `devupstream/efaktura-web`: Fastify + Drizzle + Postgres, React + Vite, тестови vitest/PGlite (157).
- Сервер Oracle (OCI) VM `https://92-5-149-62.sslip.io`, Docker. CI ја гради сликата `ghcr.io/devupstream/efaktura-api:YYYYMMDD-<sha>`. Табелата со слики и командата за распоредување се во docs/06.
- Распоредување (го пуштам јас од PowerShell; никогаш `sudo` на Windows; SSH-клучот е само кај мене):
  `ssh -i "$env:USERPROFILE\.ssh\oracle-efaktura.key" ubuntu@92.5.149.62 "sudo bash ~/efaktura-deploy/03-deploy.sh <tag>"`
- **Праќање на УЈП** (docs/15): „Прати на УЈП“ → редица → агент на компјутерот со токенот (`Send-ServerInvoices.ps1`) → JWS → EUID, QR, статус „Качена на УЈП“. Секој клиент може да има свој агент (клуч врзан за фирма, „Преземи агент“, `Install-Agent.ps1`, „Вклучи агент“ = линк `efaktura-agent:`).
- **УЈП тест:** JSON поминува (полето `docItemTotalOriginalPriceWoVat` не се праќа – E4018). Блокира **E5004 „Certificate is null“**: новиот сертификат на Адис (KIBS G3, сериски 155767815988223577600788196027956094007825407508) уште не е активен кај е-Фактура (во профилот стои стариот 1212…). Пратена е-пошта до УЈП; чекам одговор.
- Изводи: Халк/Шпаркасе TXT, Стопанска TXT (само TXT), НЛБ MT940; редослед по датум и континуитет (docs/08).

**Документи (во проектот и во git `docs/`)**
- 06 – сервер, слики, лекции · 08 – плаќања и изводи · 11 – пренос од ERPNext · 12 – Денес, ИОС, извоз · 13 – КИФ/КУФ · 14 – трошковни места, картица
- 15 – праќање на УЈП, агент по клиент · `ujp-efaktura-analiza.md` – официјалното API на УЈП · `agent/` – скриптите на агентот

**Отворено (по ред)**
1. **Прво успешно праќање на УЈП тест** (чека сертификатот кај УЈП). Потоа: статуси од УЈП (прифатена/одбиена од купувачот), е-пошта кога агент на фирма не работи.
2. Прв клиент со свој агент: клуч за фирма → „Преземи агент“ → `Install-Agent.ps1` на неговиот компјутер (Windows, PowerShell 7, токен, DigPotpis).
3. Мои задачи: OCI Lifecycle правила за бекапот (`dnevni/` бриши по 400 дена, `mesecni/` Archive); UptimeRobot за `/api/health` и `/api/health/agent`; проба за враќање на бекапот (`05-restore-test.sh`).
4. Сметководител: КИФ/КУФ, рок на чување 30 год. (потсетник 25.11).
5. UPSTREAM: повторен увоз на сите изводи (старите избришани 12.11), Горан Цветковски како партнер (позајмица), сопствени сметки (НЛБ, ВИСА), почетна залиха, цени.
6. Чекаат одобрување: е-пошта (M365 Graph), девизни фактури, 110 од добавувач, одобрување пред плаќање, домен и Hetzner, стари фактури 2023/2024, бришење на името од git историјата (force-push).

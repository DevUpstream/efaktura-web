# 14 – Трошковни места и картица на партнер (12.11.2026)

Одобрено 12.11.2026 (дизајн во разговорот; сите точки „OK“).

## Трошковно место (ТМ)
| Дел | Правило |
| --- | --- |
| Режим по фирма | Мени **Трошковни места**: Исклучено (почетно) / Опционално / Задолжително. Менува само администратор. |
| Шифрарник | `cost_centers` (шифра уникатна по фирма, без разлика на големи/мали букви), активно/исклучено. |
| На документ | Излезна и влезна фактура: поле **Трошковно место**. Копче **„по ставки“** → ТМ по ставка. Ставка без свое ТМ го зема ТМ од документот. |
| Задолжително | Без ТМ (на документот или на сите ставки) фактурата не се издава, а влезната не се книжи. Понудите – не. |
| По издавање / книжење | ТМ смее да се смени (копче „Зачувај ТМ“). Тригерите дозволуваат **само** `cost_center_id`; сè друго останува заклучено. Секоја промена → ревизија (`cost_center`). |
| Копирај, сторно, корекција | Го носат ТМ од оригиналот. |
| Масовно доделување | Трошковни места → „Масовно доделување“: излезни/влезни, период, партнер, „само без ТМ“ → „Провери колку“ → „Додели“. ТМ на документот; ставките со свое ТМ остануваат. |
| Извештај | Приходи (КИФ) – трошоци (КУФ), нето, по ТМ + „Без ТМ“. Иста селекција како КИФ/КУФ: сторно и одобрение со минус, корекција = разлика. Клик → документи. CSV. |
| Не е вклучено | ТМ на трошоци од изводи; почетно ТМ по партнер/артикл (фаза 3). |

## Картица на партнер
| Дел | Правило |
| --- | --- |
| Каде | Страница на партнер → **Картица**; Плаќања и наплата → **Картици** (збирно по партнери). PDF и CSV. |
| Купувач | Должи: фактура, авансна, задолжување, корекција (разлика). Побарува: уплата, одобрение, сторно, компензација. Салдо > 0 = ни должи. |
| Добавувач | Побарува: влезна фактура. Должи: наше плаќање, компензација. Салдо > 0 = ние должиме. |
| Заедно | Сè од страна на купувач. **Салдото = салдото во ИОС на истиот ден** (задолжителен тест). |
| Датуми | Излезни: датум на издавање; влезни: датум на прием; плаќања: датум на плаќање. Почетно салдо = сè пред „од“. |
| Назив | „Картица на купувач / добавувач“ – **не** е главна книга ни конто картица на сметководителот. |

## Поправено при работата
- **ИОС на ден** не ги броеше фактурите што подоцна се коригирани или сторнирани (го гледаше денешниот статус). Сега: фактура е во ИОС ако корекцијата/сторното е издадено **по** тој ден. Го откри тестот „картица = ИОС“.

## Отворено / за 10
- Почетни салда по партнер (рачен внес на датум на премин) – не се направени (одлуката не е донесена).
- Заклучување на период (по него ТМ не се менува).
- ТМ на трошоци од изводи; почетно ТМ по партнер и артикл.
- Усогласување со картиците на сметководителот.

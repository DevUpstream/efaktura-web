## 28 – Поништи извод

| Правило | Како |
| --- | --- |
| Кој | Само администратор; задолжителна причина |
| Што се случува | Сите уплати од изводот се сторнираат (причина „Поништен извод бр. N: …“), фактурите повторно се отворени; изводот и ставките добиваат `voided_at` |
| Што не се брише | Ништо: изводот останува видлив („поништен“), уплатите остануваат како сторнирани, научените жиро-сметки остануваат |
| Повторен увоз | Истиот извод може повторно да се увезе (уникатните индекси важат само за непоништени) |
| Континуитет, трошоци, „Денес“ | Поништениот извод не влегува |
| На поништена ставка | Нема книжење ни промена на вид |

## 9 – Гаранција и сериски броеви

### Гаранција
- Кај артиклот: „Гаранција (месеци)“, 1–600, празно = без гаранција.
- Ставката на фактурата ја чува гаранцијата при зачувување (снимка). На PDF под описот: „Гаранција 24 мес., до 17.11.2028“ (од датумот на промет; кај понуда не се печати).
- Испратница: истото, од датумот на испратницата.

### Сериски броеви (по избор)
- Кај артиклот: „Следење по парче / серија“ = Без / Лот и рок / **Сериски број**. Лот и сериски број не одат заедно.
- Вклучување само кога артиклот **нема залиха** (постоечката залиха нема броеви).
- Табели: `serial_numbers` (каде е сега; `warehouse_id = null` = не е на залиха) и `serial_moves` (секое движење, +1 / −1, со документот).

| Документ | Правило |
| --- | --- |
| Приемница, влезна фактура | Точно еден број по парче; количината цел број; бројот не смее да е веќе на залиха |
| Фактура, испратница, отпис, пренос | Бројот мора да е во тој магацин. „Избери од залиха“ ги нуди броевите на залиха. Без залиха во минус |
| Фактура од испратница | Броевите од испратницата одат на фактурата (без второ издавање) |
| Сторно (фактура, корекција, магацински документ, пренос) | Се враќаат истите броеви |
| Попис | Не се прави по сериски број (порака: приемница или отпис) |
| Производство | Не е поддржано за артикл со сериски број (грешка „внесете сериски броеви“) |

**Магацин → Сериски броеви:** пребарување по дел од бројот; картица: каде е, кога и на кого е продаден, „Гаранција до“ (истечена = црвено), сите документи.
На фактура и испратница: „Сер. бр.: …“ под описот.

[ПРЕТПОСТАВКА] Гаранцијата тече од датумот на промет на фактурата (или од датумот на испратницата). Ако треба од датумот на испорака – да се каже.
